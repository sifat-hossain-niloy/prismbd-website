# prismbd.net (original site)

The original Prism Venture website, hosted on GitHub Pages at <https://prismbd.net>.

These files are the **compiled build** (a Next.js 15 static export) of the original site, exactly as it ran on the old HostGator hosting. The editable source code (`package.json`, `app/`, `components/` and so on) is not included, so content changes need that source from the original developer.

- `.nojekyll` is required: without it GitHub Pages skips the `_next/` folder and the site loads without styles or scripts.
- `CNAME` sets the custom domain `prismbd.net`.

The redesigned version made in October 2026 is archived at https://github.com/sifat-hossain-niloy/prismbd-new-design.
